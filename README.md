BELLASTORE

O sistema “Bellastore” tem como principal objetivo atender demandas de beleza em vestimenta, através de reutilização de roupas dos criadores e usuários que desejarem fazer parte do alinhamento de vendas, realizando o atendimento de forma básica e acessível às pessoas, buscando sempre agradar cada cliente e seu gosto individual.

O aplicativo teve todo seu wireframe - base visual, mas, ainda, não usual - desenvolvido com auxílio do uso de ferramenta de inteligência artificial, como sendo uma ferramenta de design colaborativa que permite a criação de interfaces de sites, aplicativos e outras experiências digitais, oferecendo funcionalidades de design. Nessa lógica, nós desenvolvemos 8 telas múltiplas, dentre elas estão: a tela de login; a tela inicial, na qual será possível ter uma visão geral do sistema, tendo opções que o usuário pode acessar; a tela de produtos, geralmente voltada para visualizar os produtos oferecidos pelo bazar; a tela de detalhes de produtos, que permite o usuário consiga escolher cor e tamanho da vestimenta; Tela de carrinho, na qual geralmente o usuário vai finalizar sua compra; e telas complementares para o complemento de uso, como a tela de login, para que o usuário acesse sua conta; tela de cadastro, onde permite o usuário criar um perfil para acessar o bazar; tela minha conta, que mostra as informações do usuário; e tem também a tela de contatos que permite que o usuário tenha contato com os desenvolvedores do projeto.
